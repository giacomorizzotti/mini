A "mini" frontend framework made to build wonderful and technically perfect websites, in minutes.

<br/>

### Installation

```sh
git clone https://github.com/giacomorizzotti/mini
```

Or load it from the CDN:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/giacomorizzotti/mini@main/css/mini.min.css">
<script src="https://cdn.jsdelivr.net/gh/giacomorizzotti/mini@main/js/mini.js"></script>
```

<br/>

### What's inside

- `css/` SCSS source and the compiled `mini.css` and `mini.min.css`
- `js/` vanilla JS helpers
- `img/` brand assets and icons
- `one-page/` a single-page PHP template

<br/>
